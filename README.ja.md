# Outfit Gallery 1.0.0 — 導入と使い方

写真を見ながら、装備一式・頭装備・小物を切り替えられるSKSEプラグインです。

## 必要環境

Skyrimに対応するSKSE、Address Library、SKSE Menu Framework 3とその依存MODを導入してください。フレームワークのイベント優先度・入力イベントAPIを使用します。古い非対応版では起動できません。

Steam版1.5.97と1.6.1170で開発中の実機確認があります。主な検証環境は1.6.1170です。1.6.353／1.6.640／1.6.1130はDLLの対応対象ですが実機未検証です。GOG／VR／それ以外のバージョンには対応していません。

SmoothCamとTrue Directional Movementは任意です。衣装・ウィッグ・アクセサリ・フォントは含まれません。登録した装備の元MODが必要です。

## 導入・更新

ゲーム終了後、配布ZIPをMO2などでインストールし、SKSEから起動してください。ESPはありません。
更新時は写真・登録・設定が入る `Data/SKSE/Plugins/OutfitGallery/` を保持してください。MO2では通常Overwrite、または既に同じファイルを提供するMOD内に保存されます。カスタマイズしたINIも保持してください。

初期起動キーはF8、ゲームパッドはBack／Viewの0.8秒長押しです。最初は英語表示です。OptionsのLanguageから日本語に変更できます。日本語表示にはMenu Framework側の日本語対応フォント設定が必要です。

## 登録と着替え

- 装備：身につけている装備一式を登録。文字のタブから選ぶと装備一式を交換します。
- 頭装備：指定した頭スロットのみ登録。人アイコンから選ぶと、他の装備はそのまま頭装備だけを変更します。対象スロットは30・31・41・42から選択できます。
- 小物：追加したい装備だけを身につけて登録。指輪アイコンから選ぶと登録装備を追加し、同じスロットに装備がある場合は交換します。自動でアクセサリだけを判別する機能ではありません。

頭装備・小物は専用の一覧に入り、「すべて」や通常の分類タブには入りません。登録直後は該当するタブで新しい写真を選択します。右上の「?」からヘルプを開けます。

## 初期操作

| 操作 | キーボード・マウス | ゲームパッド |
| --- | --- | --- |
| 装備を登録 | F9 | Y |
| 頭装備を登録 | F10 | X |
| 小物を登録 | F11 | 左スティック押し込み |
| 装備を適用 | 写真をクリック | A |
| 選択 | マウス | 十字キー・左スティック |
| タブ移動 | タブをクリック | LB／RB |
| 頭装備／小物タブ | アイコンをクリック | L2／R2 |
| 写真メニュー | 写真を右クリック | 右スティック押し込み |
| 列数変更 | 格子アイコンをクリック | タブから左右で格子アイコンへ移動しA |
| 閉じる | 右上X・Esc | B |

写真の最上段から上でタブへ、下で写真へ戻ります。起動キー・登録キー・長押し時間はオプションで変更できます。他MODと入力が重なる場合は別のボタンを指定してください。

右の撮影枠は左ドラッグで上下左右、右ドラッグで回り込み・見上げ見下ろし、ホイールで距離を調整できます。カメラプリセット1は初期構図に固定、2～7は保存可能です。既存フリーカメラからの起動は試用機能です。

## データと制限

写真・登録・分類・カメラ・キー設定はセーブ外に保存され、ニューゲームでも使えます。`Data/SKSE/Plugins/OutfitGallery/` 全体をバックアップしてください。

未所持の装備は「不足している装備を追加」で復元できます。基本アイテムを記録する方式のため、強化値・自作付呪・独自名称・毒・魔法・シャウトは復元しません。元MODの削除やFormID変更、複数スロット装備の競合などでは適用できない場合があります。

ツールが追加した装備は識別できたものだけを管理し、着替えが確認できた後に不要になったものを回収します。元から所持した装備は残します。識別が曖昧なもの・移動や加工をしたもの・管理開始前の装備などは残る場合があります。この管理情報はキャラクターのSKSEコセーブに保存されるため、セーブの`.ess`と`.skse`は一緒に保持してください。ごみ箱の完全削除は写真と登録情報を削除する操作です。

文字が「?」になる場合はMenu Frameworkのフォント設定、画面がぼやける場合は同フレームワークのBlurBackgroundOnMenuや被写界深度の設定を確認してください。

1.0.0は正式公開用のバージョン表記・説明書整理です。機能は実機確認済み0.14.9から変更していません。1.0.0そのものの実ゲーム確認は未実施です。
